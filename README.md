# 🍪 Cookie Crawl

A cozy Christmas idle event for fans, friends & subscribers.

Send helpers on winter journeys → gather ingredients → bake cookies → climb the leaderboard.

## Live Demo

Deploy this repo to Vercel in one click:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Lag0ndev/cookie-crawl)

Or just import the repo at [vercel.com/new](https://vercel.com/new).

## Local

Just open `index.html` or run any static server.

```bash
npx serve .
```

## Stack

- Pure HTML + CSS + a tiny bit of JS
- No build step needed
- Perfect for Vercel static hosting
